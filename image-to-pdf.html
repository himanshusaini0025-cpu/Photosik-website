What the Image to PDF tool does

Image to PDF combines any number of photos or graphics into a single, well-formatted PDF document, with full control over page size, layout, image quality and file size. It's the tool to reach for when you need to send, print or archive a batch of images as one shareable file instead of a folder of loose pictures.

How it works

Each image is read directly in your browser, re-encoded at the quality level you choose, and placed onto a PDF page built to your chosen size, orientation and margins. Nothing is uploaded anywhere — the whole conversion, including the live preview, runs locally using your device's own processing power.

How to use it

  1. Drag in your images, or use Choose Images to pick them from your device.
  2. Drag a thumbnail to reorder it, or remove one with its ✕ button.
  3. Adjust the PDF Options — page size, orientation, margins, image fit, quality and more.
  4. Press Preview to check the result, then Create PDF to download it.

Formats and file size

JPG, JPEG, PNG, WebP, BMP and GIF images are accepted as input, up to 50MB each, and the output is always a single PDF. File size depends mainly on the quality and compression levels chosen and on how many images are packed onto each page — the estimated size shown above the preview updates as you adjust these settings.

Common use cases

Useful for turning a set of scanned pages or receipts into one document, packaging a photo set for printing, assembling a portfolio or lookbook, or preparing a batch of images for an application or submission that only accepts a single PDF file.
